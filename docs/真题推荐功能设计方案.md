# 真题推荐功能设计方案

## 1. 功能目标

根据用户的学习进度、历史答题数据和目标考试类型，智能推荐适合的真题内容。

## 2. 核心功能模块

### 2.1 用户画像分析模块

#### 数据模型

- **UserProfile**：用户画像主表
  - userId：用户ID
  - studyProgress：学习进度分数
  - targetExamType：目标考试类型
  - overallCorrectRate：总体答题正确率
  - lastStudyTime：最近学习时间

- **UserSubjectPreference**：用户学科偏好
  - userId：用户ID
  - subjectId：学科ID
  - subjectName：学科名称
  - preferenceScore：偏好分数
  - answerCount：答题次数
  - correctCount：正确次数

- **UserWeakKnowledge**：用户薄弱知识点
  - userId：用户ID
  - knowledgeId：知识点ID
  - knowledgeName：知识点名称
  - subjectId：学科ID
  - masteryLevel：掌握程度（0-100）
  - errorCount：错误次数
  - lastErrorTime：最近错误时间

- **UserAnswerRecord**：用户答题记录
  - userId：用户ID
  - questionId：题目ID
  - questionType：题目类型
  - subjectId：学科ID
  - knowledgeId：知识点ID
  - result：答题结果（0：错误，1：正确）
  - answerTime：答题时间（秒）
  - difficultyLevel：难度级别

#### API接口

- `getUserProfile(Long userId)`：获取用户画像
- `updateUserProfile(UserProfile userProfile)`：更新用户画像
- `getUserSubjectPreferences(Long userId)`：获取用户学科偏好
- `getUserWeakKnowledge(Long userId, Integer limit)`：获取用户薄弱知识点
- `recordUserAnswer(Long userId, String questionId, String questionType, String subjectId, String knowledgeId, Integer result, Integer answerTime, Integer difficultyLevel)`：记录用户答题

### 2.2 真题资源管理模块

#### 数据模型

- **ExamPaper**：真题试卷
  - paperId：试卷唯一标识
  - year：年份
  - examType：考试类型
  - subjectId：学科ID
  - subjectName：学科名称
  - paperName：试卷名称
  - totalQuestions：总题数
  - totalScore：总分数
  - difficulty：难度系数
  - source：来源
  - analysisStatus：解析状态

- **ExamQuestion**：真题题目
  - questionId：题目唯一标识
  - paperId：试卷ID
  - questionType：题目类型
  - content：题目内容
  - options：选项（JSON格式）
  - correctAnswer：正确答案
  - analysis：解析
  - score：分数
  - difficultyLevel：难度级别
  - knowledgeId：知识点ID
  - knowledgeName：知识点名称
  - subjectId：学科ID
  - subjectName：学科名称
  - year：年份

- **ExamQuestionTag**：真题题目标签
  - questionId：题目ID
  - tagName：标签名称
  - tagType：标签类型

#### API接口

- `getExamPapers(String subjectId)`：获取学科真题试卷
- `getExamPapersByType(String examType)`：获取指定考试类型的试卷
- `getPaperDetail(String paperId)`：获取试卷详情
- `getPaperQuestions(String paperId)`：获取试卷题目
- `getRecommendedPapers(Long userId, String subjectId, Integer limit)`：获取推荐试卷
- `getRecommendedQuestions(Long userId, String subjectId, Integer limit)`：获取推荐题目

### 2.3 推荐算法模块

#### 推荐策略

1. **基于用户画像的推荐**
   - 考虑用户的学习进度、答题正确率、薄弱知识点等因素
   - 推荐与用户当前水平匹配的真题

2. **基于协同过滤的推荐**
   - 分析相似用户的答题行为
   - 推荐相似用户表现较好的真题

3. **基于内容特征的推荐**
   - 分析真题的知识点、难度、题型等特征
   - 推荐与用户偏好匹配的真题

4. **混合推荐**
   - 综合以上三种策略
   - 权重分配：用户画像(40%) + 协同过滤(30%) + 内容特征(30%)

#### 算法实现

- **用户相似度计算**：基于余弦相似度算法
- **物品相似度计算**：基于内容特征的相似度
- **推荐分数计算**：综合多维度因素

## 3. 界面交互设计

### 3.1 推荐结果展示

- **展示内容**：
  - 真题年份、名称
  - 考试类型、学科
  - 难度系数、总题数
  - 真题来源
  - 推荐理由

- **交互功能**：
  - 收藏功能：用户可以收藏感兴趣的真题
  - 查看详情：查看真题的详细信息
  - 开始练习：直接进入练习模式

### 3.2 换一批功能

- 支持用户点击"换一批"按钮刷新推荐结果
- 每次刷新时重新调用推荐算法生成新的推荐列表

### 3.3 辅助功能

- **真题收藏**：用户可以收藏重要的真题
- **错题标记**：用户可以标记错题以便后续复习
- **练习记录**：记录用户的练习历史和成绩

## 4. 性能优化

### 4.1 缓存策略

- **Redis缓存**：
  - 推荐结果缓存（6小时）
  - 用户画像缓存（12小时）
  - 真题数据缓存（24小时）

### 4.2 数据库优化

- **索引优化**：为频繁查询的字段创建索引
- **分页查询**：避免一次性加载大量数据
- **批量操作**：减少数据库交互次数

### 4.3 算法优化

- **预计算**：离线计算用户相似度和物品相似度
- **增量更新**：实时更新用户画像和推荐结果
- **并行计算**：使用多线程提高推荐算法性能

## 5. 数据安全

### 5.1 数据加密

- **敏感数据加密**：用户答题记录、学习数据等敏感信息加密存储
- **传输加密**：使用HTTPS确保数据传输安全

### 5.2 访问控制

- **身份认证**：基于JWT的身份认证
- **权限控制**：细粒度的权限管理
- **审计日志**：记录用户操作日志

### 5.3 数据保护

- **数据脱敏**：对敏感数据进行脱敏处理
- **数据备份**：定期备份用户数据
- **合规性**：符合相关数据保护法规
